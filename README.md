# TwinStock Guard — public website

Static marketing and legal site for TwinStock Guard, served by GitHub Pages:
https://zarych.github.io/twinstock-guard-site/

- Plain HTML + CSS. No build step, no JavaScript, no cookies, no analytics, no third-party assets.
- Pages: `/` (landing), `/privacy/`, `/terms/`, `/support/`, plus `404.html`, `sitemap.xml`, `robots.txt`.
- Deploys automatically from the `main` branch (repository root).

The privacy policy and terms are drafts and must be reviewed by the owner before launch.

Preview locally: `python3 -m http.server 8000` and open http://localhost:8000/.
